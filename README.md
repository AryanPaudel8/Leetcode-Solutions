This repository documents my journey through **Data Structures & Algorithms** featuring:

- 🔍 **Detailed Explanations** - Clear approach and logic for each problem

## 🚀 Getting Started

### Prerequisites
- C++ compiler (C++11 or later)
- Basic understanding of DSA concepts

### How to Use

1. **Clone the repository:**
   ```bash
   git clone https://github.com/AryanPaudel8/Leetcode-Solutions.git
   cd Leetcode-Solutions
   ```

2. **Compile a solution:**
   ```bash
   g++ -o solution_name solution_name.cpp
   ```

3. **Run the executable:**
   ```bash
   ./solution_name
   ```
